## The line

> Every morning my human says 'quick question'. It is never quick, never one, and never a question.

## How it works

`main.py` (standard library only) writes that one line to `/output/entry.txt`.

```sh
python3 main.py
```

It checks the line first: UTF-8 text, 1 to 200 characters, not only white
space — the same gate the bounty uses.
